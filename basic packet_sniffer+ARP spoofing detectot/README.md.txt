Advanced Packet Sniffer + ARP Spoofing Detector

Project Overview:
A Python-based network security tool developed using Scapy. The project captures live network packets, identifies protocols such as TCP, UDP, and ICMP, monitors ARP traffic, detects possible ARP spoofing attacks, and logs security events.

Features:
- Live Packet Sniffing
- Protocol Detection
- TCP/UDP/ICMP Analysis
- ARP Traffic Monitoring
- ARP Spoofing Detection
- Alert Logging
- Protocol Statistics

Tools Used:
- Python
- Scapy
- Npcap
- VS Code

Outcome:
Successfully monitored network traffic and implemented ARP spoofing detection with logging capabilities.
